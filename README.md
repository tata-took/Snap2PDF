# Kindle PDF Converter

Kindleアプリで表示中の書籍を自動的にスクリーンショット撮影し、画像を統合してPDFファイルとして出力するデスクトップアプリケーションです。

## 機能

### 📸 スクショ撮影モード
- ✨ Kindleアプリの自動ページめくり
- 📸 画面の自動スクリーンショット撮影（複数回撮影対応）
- 💾 画像をフォルダに保存（手動で不要な画像を削除可能）
- 📊 進捗表示と残り時間推定

### 📄 PDF変換モード
- 🖼️ 撮影済み画像フォルダからPDF生成
- 🎨 最高画質で出力（圧縮なし）
- 📦 サイズ超過時は自動的に複数PDFに分割
- 👁️ 変換前に画像を確認・選定可能

### その他
- ⚙️ 設定の保存・読み込み
- 🎨 ダークモードUI

## 対応環境

- **OS**: Windows 11 (64bit)
- **必須**: Kindle for PC アプリ
- **Python**: 3.10以上（開発時のみ）

## インストール

### 方法1: Python環境がある場合

```bash
# リポジトリのクローン
git clone https://github.com/yourusername/Snap2PDF.git
cd Snap2PDF

# 依存パッケージのインストール
pip install -r requirements.txt

# 実行
python main.py
```

### 方法2: 実行ファイル（EXE）を使用

単体で実行可能な `.exe` ファイルを自分でビルドできます。

**Windows:**
```bash
# リポジトリのクローン
git clone https://github.com/yourusername/Snap2PDF.git
cd Snap2PDF

# ビルド（バッチファイルを実行）
build.bat
```

ビルドが完了すると `dist/KindlePDFConverter.exe` が生成されます。

**注意:**
- 初回ビルドには数分かかります
- Python 3.10以上がインストールされている必要があります
- 生成されたEXEファイルは `dist` フォルダ内にあります
- EXEファイルは単体で動作し、Pythonのインストールは不要です

## 使い方

本アプリは2段階のワークフローで動作します：

### 📸 ステップ1: スクリーンショット撮影

1. **Kindleアプリを起動し、変換したい書籍を開く**
   - 最初のページ（変換開始したいページ）を表示しておきます

2. **Kindle PDF Converterを起動**
   - `main.py` を実行、または配布exeファイルを実行
   - 「📸 スクショ撮影」タブを選択（デフォルト）

3. **スクショ設定を入力**
   - **総ページ数**: 変換したいページ数を入力
   - **開始ページ**: 現在表示中のページ番号を入力
   - **読み方向**: 右開き（通常の本）または左開き（漫画など）を選択
   - **スクショ回数/ページ**: 各ページで何回撮影するか（推奨: 2-3回）
   - **保存先**: 画像を保存するフォルダを指定

4. **「▶ スクショ開始」ボタンをクリック**
   - 自動的にページをめくりながらスクリーンショットを撮影します
   - 処理中は画面に触れないでください
   - 進捗バーと残り時間が表示されます

5. **撮影完了**
   - 完了すると自動的に「📄 PDF変換」タブに切り替わります
   - 画像は指定したフォルダに保存されています

### 🖼️ ステップ2: 画像の確認と選定

6. **「🖼️ フォルダを開く」ボタンをクリック**
   - 撮影した画像がエクスプローラーで表示されます

7. **不要な画像を手動で削除**
   - 各ページで複数枚撮影した場合、最良の1枚を残して他を削除
   - ぼやけている画像、読み込み中の画像などを削除
   - 不要なページ全体を削除することも可能

### 📄 ステップ3: PDF変換

8. **PDF設定を確認**
   - **画質**: 常に最高画質（圧縮なし）
   - **PDFサイズ上限**: 1ファイルあたりの最大サイズを指定（デフォルト: 50MB）
   - **出力先**: PDFの保存先を指定

9. **「📄 PDF生成」ボタンをクリック**
   - 選定した画像から最高画質のPDFが生成されます
   - サイズ超過時は自動的に複数PDFに分割されます（output_1.pdf, output_2.pdf...）

10. **完了！**
    - 指定した場所にPDFが保存されます
    - 複数ファイルに分割された場合は、完了メッセージに全ファイルの一覧が表示されます

### 詳細設定

#### スクショ撮影の設定
- **ページめくり待機**: ページ送り後の待機時間（デフォルト: 1.5秒）
  - ネットワークが遅い場合は長めに設定
- **初回読み込み待機**: 処理開始直後の待機時間（デフォルト: 3.0秒）
- **スクショ回数/ページ**: 各ページで撮影する回数（1-10回）
  - ページ読み込みが遅い場合は複数回撮影を推奨
  - 複数回撮影した場合、後で手動で最良の1枚を選べます
- **スクショ間隔**: 複数回撮影時の間隔（デフォルト: 0.5秒）

#### PDF変換の設定
- **画質**: 常に最高画質（圧縮なし）で出力
- **PDFサイズ上限**: 1ファイルあたりの最大サイズ（MB）を指定
  - サイズ超過時は自動的に複数PDFに分割
  - 例: 200ページで上限50MBの場合 → output_1.pdf, output_2.pdf, output_3.pdf, output_4.pdf
  - 推定サイズ欄で事前に分割数を確認可能

## 設定の保存

「設定保存」ボタンをクリックすると、現在の設定が保存され、次回起動時に自動的に読み込まれます。

保存場所: `%USERPROFILE%/.kindle_pdf_tool/config.json`

## トラブルシューティング

### スクショ撮影時

#### Kindleウィンドウが見つからない
- Kindleアプリが起動していることを確認
- 書籍が開かれていることを確認
- ウィンドウが最小化されていないことを確認

#### スクリーンショットが真っ白/真っ黒
- 待機時間を長めに設定（2.0秒以上）
- スクショ回数を増やす（3回以上）
- スクショ間隔を長めに設定（0.7秒以上）
- 撮影後、画像フォルダで確認し、不要な画像を削除

#### 処理が途中で止まる
- 「⏹ 停止」ボタンで安全に停止できます
- ログファイルを確認してエラー内容を確認
- 撮影済みの画像は保存されています（PDF変換モードで利用可能）

### PDF変換時

#### ファイルサイズが大きすぎる
- PDFサイズ上限を小さく設定（例: 30MB/ファイル）
- 自動的に複数PDFに分割されます
- 画像フォルダで不要なページを削除

#### 画像が見つからない
- 画像フォルダが正しく選択されているか確認
- フォルダ内にjpg/jpeg/png形式の画像があるか確認
- 「🖼️ フォルダを開く」ボタンで内容を確認

```

```


**スクショ撮影:**

```
PDFサイズ上限: 100MB/ファイル
```

**スクショ撮影:**
```
総ページ数: 実際のページ数

```

**PDF変換:**
```
PDFサイズ上限: 100MB/ファイル
```

## 処理時間の目安

| ページ数 | 設定 | 推定時間 |
|---------|------|---------|
| 100ページ | 標準（スクショ1回） | 3-5分 |
| 200ページ | 標準（スクショ1回） | 5-10分 |
| 200ページ | 高品質（スクショ3回） | 10-15分 |
| 500ページ | 標準（スクショ1回） | 15-25分 |

※ PC性能やKindleアプリの読み込み速度により変動します

## 開発

### プロジェクト構造

```
Snap2PDF/
├── main.py                          # エントリーポイント
├── requirements.txt                 # 依存パッケージ
├── README.md                        # このファイル
├── build.bat                        # Windowsビルドスクリプト
├── build.sh                         # Linux/Macビルドスクリプト
├── kindle_pdf_converter.spec        # PyInstallerビルド設定
└── kindle_pdf_tool/
    ├── __init__.py
    ├── gui/
    │   ├── __init__.py
    │   ├── main_window.py          # メインウィンドウ
    │   ├── components.py           # UIコンポーネント
    │   └── image_review_window.py  # 画像確認ウィンドウ
    ├── core/
    │   ├── __init__.py
    │   ├── capture.py              # スクリーンショット処理
    │   ├── automation.py           # 自動化ロジック
    │   └── pdf_generator.py        # PDF生成・分割
    └── utils/
        ├── __init__.py
        ├── config.py               # 設定管理
        └── logger.py               # ログ管理
```

### EXEファイルのビルド方法

**Windows:**
1. リポジトリをクローン
2. `build.bat` を実行
3. `dist/KindlePDFConverter.exe` が生成されます

**Linux/Mac:**
1. リポジトリをクローン
2. `./build.sh` を実行
3. `dist/KindlePDFConverter` が生成されます

**詳細:**
- `kindle_pdf_converter.spec` ファイルでビルド設定をカスタマイズできます
- アイコンを追加する場合は、`.spec` ファイルの `icon=None` を変更してください
- ビルドには PyInstaller が使用されます
