# Kindle PDF Converter

Kindleアプリで表示中の書籍を自動的にスクリーンショット撮影し、画像を統合してPDFファイルとして出力するデスクトップアプリケーションです。

## 機能

- ✨ Kindleアプリの自動ページめくり
- 📸 画面の自動スクリーンショット撮影
- 📄 高品質なPDF生成
- 🗜️ ファイルサイズの最適化（5段階の圧縮レベル）
- 📊 進捗表示と残り時間推定
- ⚙️ 設定の保存・読み込み

## 対応環境

- **OS**: Windows 11 (64bit)
- **必須**: Kindle for PC アプリ
- **Python**: 3.10以上（開発時のみ）

## インストール

### 方法1: Python環境がある場合


今後、単体で実行可能な `.exe` ファイルを配布予定です。

## 使い方

### 基本的な手順

1. **Kindleアプリを起動し、変換したい書籍を開く**
   - 最初のページ（変換開始したいページ）を表示しておきます

2. **Kindle PDF Converterを起動**
   - `main.py` を実行、または配布exeファイルを実行

3. **設定を入力**
   - **総ページ数**: 変換したいページ数を入力
   - **開始ページ**: 現在表示中のページ番号を入力
   - **読み方向**: 右開き（通常の本）または左開き（漫画など）を選択

4. **「▶ 開始」ボタンをクリック**
   - 自動的にページをめくりながらスクリーンショットを撮影します
   - 処理中は画面に触れないでください

5. **完了を待つ**
   - 進捗バーと残り時間が表示されます
   - 完了すると指定した場所にPDFが保存されます

### 詳細設定

#### ページ操作
- **ページめくり待機**: ページ送り後の待機時間（デフォルト: 1.5秒）
  - ネットワークが遅い場合は長めに設定
- **初回読み込み待機**: 処理開始直後の待機時間（デフォルト: 3.0秒）

#### キャプチャ設定
- **スクショ回数**: 各ページで撮影する回数（1-10回）
  - ページ読み込みが遅い場合は複数回撮影を推奨
- **スクショ間隔**: 複数回撮影時の間隔（デフォルト: 0.5秒）
- **保存方法**:
  - **最後の1枚のみ**: 最後に撮影したスクショを使用（高速）
  - **すべて保存**: 全スクショをPDFに含める（ファイルサイズ大）
  - **最良画質を自動選択**: 最もファイルサイズが大きいものを選択

#### PDF設定
- **圧縮レベル**: 1（高画質）〜 5（低画質・小サイズ）
  - レベル3（中画質）がバランス良好
- **目標ファイルサイズ設定**:
  - 有効にすると指定サイズ以下になるよう調整
  - **画質優先**: 目標超過時も警告のみ
  - **サイズ優先**: 自動的に再圧縮を実行

## 設定の保存

「設定保存」ボタンをクリックすると、現在の設定が保存され、次回起動時に自動的に読み込まれます。

保存場所: `%USERPROFILE%/.kindle_pdf_tool/config.json`

## ログ

アプリケーションの動作ログは以下の場所に保存されます：

`%USERPROFILE%/.kindle_pdf_tool/app.log`

## トラブルシューティング

### Kindleウィンドウが見つからない

- Kindleアプリが起動していることを確認
- 書籍が開かれていることを確認
- ウィンドウが最小化されていないことを確認

### スクリーンショットが真っ白/真っ黒

- 待機時間を長めに設定（2.0秒以上）
- スクショ回数を増やす（3回以上）
- 保存方法を「最良画質を自動選択」に変更

### ファイルサイズが大きすぎる

- 圧縮レベルを上げる（4または5）
- 目標ファイルサイズ設定を有効化
- 優先度を「サイズ」に設定

### 処理が途中で止まる

- 「⏹ 停止」ボタンで安全に停止できます
- ログファイルを確認してエラー内容を確認
- 一時ファイルは自動的にクリーンアップされます

## 推奨設定

### 一般的な書籍（小説など）

```
総ページ数: 実際のページ数
スクショ回数: 1回
圧縮レベル: 3（中画質）
目標サイズ: 50MB（任意）
```

### 画像が多い書籍（雑誌・技術書など）

```
総ページ数: 実際のページ数
スクショ回数: 3回
保存方法: 最良画質を自動選択
圧縮レベル: 2（中高画質）
目標サイズ: 100MB（任意）
```

### 漫画

```
総ページ数: 実際のページ数
読み方向: 右開き（または左開き）
スクショ回数: 2回
圧縮レベル: 2（中高画質）
```

## 処理時間の目安

| ページ数 | 設定 | 推定時間 |
|---------|------|---------|
| 100ページ | 標準（スクショ1回） | 3-5分 |
| 200ページ | 標準（スクショ1回） | 5-10分 |
| 200ページ | 高品質（スクショ3回） | 10-15分 |
| 500ページ | 標準（スクショ1回） | 15-25分 |

※ PC性能やKindleアプリの読み込み速度により変動します
